Fix Dropdowns

Search large dropdowns on any page with one bookmark. Everything runs in your browser, only when you click it.

Install

Desktop: show your bookmarks bar, then drag this button onto it:

🔎 Fix Dropdowns

Then visit a page with a large native dropdown and click the bookmark. You can also try it on this page now.

On iPad Safari, dragging to a bookmarks bar is awkward. See the README for manual setup. Some websites or browser policies can block bookmarklets.
