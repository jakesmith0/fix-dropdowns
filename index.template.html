Fix Dropdowns

Make one dropdown searchable at a time. Pick a field, find an option, and keep the page's original form working.

Install

Desktop: show your bookmarks bar, then drag this button onto it:

🔎 Fix Dropdowns v1.1

Then visit a page with a large native dropdown and click the bookmark. You can also try it on this page now.

On iPad Safari, dragging to a bookmarks bar is awkward. See the README for manual setup. Some websites or browser policies can block bookmarklets.

Native & dependent dropdowns

Supported

Open the bookmarklet and choose Manufacturer. Select Clenergy, then switch the panel to Product and search “solar roof pro”. Choose JA Solar to try “ja 440”. Each search stays within the field you choose.

Native event log

Grouped options

Supported

A native dropdown with option groups, accents and unavailable options. Try “cafe”. Disabled options and disabled groups must never appear in search.

Styled custom wrapper

Supported: native backing

This widget displays its own button and menu but keeps a hidden native dropdown. Picking an option in the bookmarklet must update its visible button too.

Options added later

Supported

With the panel open, add a dropdown containing 1,000 part numbers. It should appear in the picker. Search “ZX-0999” to find an option beyond the first visible results.

Pure custom widget

Not supported yet

An ARIA menu built from buttons with no native dropdown. It works normally below, but will not appear in the bookmarklet's picker. Widgets that fetch or virtualize options need specific integration; the bookmarklet only searches choices already in native dropdowns.

Controls that should be skipped

Intentionally ignored

Small lists, multiple selection and disabled controls keep their original behavior.
