Will it work on every dropdown?

It works with large standard dropdowns and some styled dropdowns that keep a standard list underneath. It currently skips short lists, multiple selection and disabled controls. Some custom menus or choices loaded from a server are not supported yet.

If it can’t find a supported dropdown, it will tell you. Some sites or browser policies also block bookmarks that run JavaScript.

What happens to my data?

The bookmark runs only when you click it. It reads the page’s dropdown choices and changes the option you select. It sends nothing to us, loads no outside code, and saves nothing.

The original website still handles your selection normally, including any requests it makes when its form changes.

Why does the bookmark have a globe icon?

The bookmark’s address is a small script, so the browser may give it a generic icon. The icon on this website cannot reliably set the icon of that bookmark. “Dropdowns” is its short name, without an emoji.

I already have an older version

Delete your old Dropdowns bookmark and drag this page’s button onto your bar again. Each bookmark contains its own copy, so existing bookmarks do not update automatically.
